How to deploy

  1. Copy deploy.sh below.
  2. Save it on the server as /root/bookmap/deploy.sh
  3. Terminal: cd /root/bookmap && ./deploy.sh
  4. Enter your GitHub username, then paste a personal access token when it asks for a password.
  5. Open the settings link the script prints, set Source: Deploy from a branch, branch main, folder / (root), Save.
  6. Wait 1-2 minutes, then open https://<you>.github.io/<repo>/ on your phone.

A token is not your account password. Create one at github.com/settings/tokens (classic, tick repo). Only paste it into your own terminal, never into a chat or a website form.

Deploy to GitHub (run this one)
#!/usr/bin/env bash
# Deploy the dashboard to GitHub Pages.
#
# Copy-paste this ONE line into your terminal:
#     cd /root/bookmap && ./deploy.sh
#
# It asks for your GitHub username and a token, pushes, then prints the
# GitHub Pages settings steps.

set -euo pipefail

REPO_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
cd "$REPO_DIR"

echo "=================================================="
echo "  GitHub Pages deploy"
echo "=================================================="
echo

command -v git >/dev/null 2>&1 || { echo "error: git is not installed" >&2; exit 1; }
[[ -d .git ]] || { echo "error: $REPO_DIR is not a git repo" >&2; exit 1; }

# ---- Username: argument, env var, or prompt -----------------------------
USER="${1:-${GITHUB_USER:-}}"
if [[ -z "$USER" ]]; then
    read -r -p "Your GitHub username (e.g. dasun): " USER
fi
[[ -n "$USER" ]] || { echo "error: username is required" >&2; exit 1; }

# ---- Repo name: argument, env var, or prompt ----------------------------
NAME="${2:-${REPO_NAME:-bookmap-pro}}"
read -r -p "Repository name [$NAME]: " ANSWER || true
[[ -n "$ANSWER" ]] && NAME="$ANSWER"

# ---- Branch: GitHub Pages is happiest with "main" ----------------------
BRANCH="$(git branch --show-current || true)"
[[ -n "$BRANCH" ]] || BRANCH=main
if [[ "$BRANCH" != "main" ]]; then
    echo "==> renaming branch $BRANCH -> main"
    git branch -M main
    BRANCH=main
fi

REMOTE="https://github.com/$USER/$NAME.git"

echo
echo "  username : $USER"
echo "  repo     : $NAME"
echo "  branch   : $BRANCH"
echo "  remote   : $REMOTE"
echo

# ---- Committer identity is required even on a fresh repo ---------------
[[ -n "$(git config user.name)" ]] || git config user.name "$USER"
[[ -n "$(git config user.email)" ]] || git config user.email "$USER@users.noreply.github.com"

# ---- Commit anything outstanding so nothing is left behind --------------
if [[ -n "$(git status --porcelain)" ]]; then
    echo "==> committing pending changes"
    git add -A
    git commit -m "Update dashboard"
fi

# ---- Wire up the remote -------------------------------------------------
if git remote get-url origin >/dev/null 2>&1; then
    echo "==> origin already set, repointing it"
    git remote set-url origin "$REMOTE"
else
    echo "==> adding origin"
    git remote add origin "$REMOTE"
fi

# ---- Push ---------------------------------------------------------------
echo
echo "==> pushing to $REMOTE"
echo "    If asked for a password, paste a GitHub token instead."
echo "    Create one: https://github.com/settings/tokens  (classic, scope: repo)"
echo
git push -u origin "$BRANCH"

# ---- Pages instructions -------------------------------------------------
cat <<EOF

==================================================
  Pushed. Now switch GitHub Pages on.
==================================================

  1. Open  https://github.com/$USER/$NAME/settings/pages
  2. Build and deployment -> Source: "Deploy from a branch"
  3. Branch: $BRANCH     Folder: / (root)
  4. Save, then wait 1-2 minutes

  Live at:  https://$USER.github.io/$NAME/

Open that link on your phone. The MEXC gate and the domain
lock are both removed, so it works on any host.
EOF
